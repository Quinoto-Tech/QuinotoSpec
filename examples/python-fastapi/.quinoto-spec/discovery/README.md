# Discovery — python-fastapi (playground)

Este directorio es el resultado real de `/quinotospec.discovery` sobre el codigo
de este ejemplo. Sirve como muestra de que genera el comando y que nivel de
detalle se espera.

## Contenido

1. `01-stack-profile.md` — Stack, comandos y test runner
2. `02-overview.md` — Resumen ejecutivo y estructura de carpetas
3. `03-architecture.md` — Capas (routes → models) y decisiones
4. `04-endpoints-and-openapi.md` — Endpoints, contratos y errores
5. `05-data-and-services.md` — Modelos, persistencia y dependencias reales
6. `06-devops-ci-security.md` — Ejecucion, CI, seguridad
7. `07-findings-and-recommendations.md` — Deuda tecnica y proximos pasos
8. `08-product-and-agreements.md` — Vision, alcance, DoR/DoD

El resto del pipeline vive en `.quinoto-spec/proposals/users-api/` (propuesta,
historias y tareas) y `.quinoto-spec/changelog/`.

Nota: en un proyecto grande estos archivos son mas extensos. La forma y las
secciones son las mismas; cambia la profundidad.
